# Scientific Visualizations

Scientific visualizations developed by **Ogetay Kayali** to explain physical concepts through motion, diagrams, and clear visual storytelling.

The repository is organized into topic folders. Each folder contains related examples, finished animations, their editable source code, and supporting explanations. File names and documentation are in English, and the animations use minimal text and universal scientific symbols wherever possible so they can be used with narration or subtitles in different languages.

## Collections

| Topic | Contents |
|---|---|
| [IceCube Neutrino Observatory](IceCube%20Neutrino%20Observatory/README.md) | Ten animations covering detector geometry, photons and neutrinos, PMTs, muon tracks, Cherenkov radiation, timing and calibration, IceCube history, electromagnetic radiation, and the Standard Model. |

Open a topic README to browse its animations, download 4K or 1080p videos, and find reproduction instructions. Each animation has a short `INFO.md` and scientific notes describing what it shows and where the representation is simplified.
