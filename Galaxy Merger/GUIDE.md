# Using Galaxy Merger

Open **`build/bin/Release/physics_view.exe`**, the single interactive application. Build instructions are in [README.md](README.md).

## Choose and run an encounter

| Viewer preset | Scene | Purpose |
| --- | --- | --- |
| Galaxy merger | `examples/galaxy_luminous_merger.scene` | Seeded arms, initial young stars, continuous formation, emission regions |
| Seeded merger | `examples/galaxy_spiral_merger.scene` | Earlier seeded-arm model with stochastic formation |
| Retrograde merger | `examples/galaxy_merger_retrograde.scene` | Alternative encounter geometry |

The unseeded prograde comparison is available through **Load scene** as `examples/galaxy_merger.scene`. The viewer accepts two-galaxy scene files. Isolated controls are generated by `physics_validate`.

**Parameters** changes initial conditions or simulation laws. Changes take effect on the next **Run** and clear the old Continue checkpoint. **Run** starts over; **Stop** pauses between steps and retains the partial recording; **Continue** resumes that state. Saving a recording preserves playback data, not a restart checkpoint.

**Resolution** changes particle counts, not galaxy mass, encounter geometry, timestep, or duration. Fine doubles the Optimal budget. Direct gravity has quadratic cost. Use matching isolated controls when assessing thickness or arm survival.

## Picture and camera

**Appearance → Picture → Optical** is the default. Expand **Stellar populations and emission lines** for independent blue-light, H-alpha, and OIII lifetimes, strengths, colors, and sizes. Dust, smoothing, arm definition, exposure, and bloom are live appearance controls. **Particles** and **Illustrative volume** reconstruct the same particle simulation differently.

**Save look / Load look** stores optical settings in plain-text `.look` files. Try `examples/broadband.look` for subdued emission or `examples/nebular.look` for stronger line contrast. Camera and galaxy colors are separate. See [the parameter reference](docs/stellar_populations.md).

| Action | Effect |
| --- | --- |
| Middle mouse drag | Orbit |
| Shift + middle mouse drag | Pan |
| Scroll | Zoom |
| Space | Pause/play |
| F | Frame trajectories |
| Esc | Close |

Camera compositions include Face-on disk, Edge-on disk, First passage, and After passage. Playback time and speed move through saved snapshots without changing integration.

## Save and export

**Save recording** writes a `.traj` file. **Load recording** opens it for playback. New V7 recordings preserve initial populations, formation cohorts, and remaining gas fractions. Older particle recordings remain readable; missing histories are not invented. Grid recordings from removed modes are rejected.

**Export** renders without the panel using the current camera and appearance:

- **Save frame** writes a PNG of the current view.
- **PNG sequence** writes numbered frames. Stop/Continue resumes within the same export session.
- **MP4 (ffmpeg)** requires ffmpeg on PATH and even frame dimensions. Stopping closes the partial video as a finished file.
- Width/Height set output resolution; From/To select simulation time. FPS is frames per simulation time unit, independent of playback speed.

Generate a recording as shown in the README, then batch-render:

```powershell
.\build\bin\Release\physics_view.exe build/merger.traj --render build/frame.png --time 4 --width 1920 --height 1080 --shot face --look examples/nebular.look
```

Options are applied in order; put `--look` before individual overrides. PNG/MP4 uses the native optical renderer. glTF exports animated particle spheres and does not reproduce optical dust or emission reconstruction.

## Scientific controls

Extract an exact isolated progenitor from the same merger scene to compare timesteps or particle budgets:

```powershell
.\build\bin\Release\physics_validate.exe examples/galaxy_luminous_merger.scene build/isolation --isolate 0 --duration 4 --half-dt --trajectories
.\build\bin\Release\physics_validate.exe examples/galaxy_luminous_merger.scene build/resolution --isolate 0 --resolution-study --duration 4
python tools/plot_isolation.py build/resolution --output build/resolution/profiles.png
```

Plotting requires NumPy and Matplotlib. See [validation and tracer workflows](docs/galaxy_visuals.md).
