# Scientific Notes: IceCube Detector Array

The schematic array contains 86 strings and 5,160 optical modules, with 60 DOMs per string. Standard vertical and horizontal spacings are approximately 17 m and 125 m; DeepCore is denser. The detector region extends approximately 1.5–2.5 km below the surface.

String positions are illustrative rather than surveyed IceCube coordinates. DOM sizes are enlarged for readability. The particle event is not measured data. Depth is introduced with a surface horizon; no enclosing cube or explanatory text is drawn.

The 4K version is rasterized directly at 3840 × 2160 using the same logical geometry, not upscaled from the 1080p video. Both resolutions are collected here. The 1080p renderer writes `timing.json`; `export.json` records the separate 4K export.
